═══════════════════════════════════════════════════════════════════════
  可用的推送脚本
═══════════════════════════════════════════════════════════════════════

您有3个推送脚本可以使用：

┌─ 脚本1：push_all_repos.sh ⭐ 推荐 ───────────────────────────┐
│                                                                    │
│  用途：推送所有内容（主仓库 + 全部5个子模块）                   │
│                                                                    │
│  推送内容：                                                         │
│  ✓ 主仓库 (gem5-gpu-bak)    - 脚本、文档、配置                │
│  ✓ gem5                     - 核心模拟器                        │
│  ✓ gem5-gpu                 - GPU集成层                         │
│  ✓ gpgpu-sim                - GPU模拟引擎                       │
│  ✓ Graphite                 - 网络模拟器                        │
│  ✓ benchmarks               - 测试基准                          │
│                                                                    │
│  使用方法：                                                         │
│  $ ./push_all_repos.sh           # 推送所有仓库                 │
│  $ ./push_all_repos.sh --main-only   # 只推送主仓库            │
│  $ ./push_all_repos.sh --subs-only   # 只推送子模块            │
│  $ ./push_all_repos.sh --help        # 显示帮助                │
└────────────────────────────────────────────────────────────────────┘

┌─ 脚本2：push_to_gitee.sh ─────────────────────────────────────┐
│                                                                    │
│  用途：只推送5个子模块（不推送主仓库）                          │
│                                                                    │
│  推送内容：                                                         │
│  ✓ gem5                     - 核心模拟器                        │
│  ✓ gem5-gpu                 - GPU集成层                         │
│  ✓ gpgpu-sim                - GPU模拟引擎                       │
│  ✓ Graphite                 - 网络模拟器                        │
│  ✓ benchmarks               - 测试基准                          │
│                                                                    │
│  使用方法：                                                         │
│  $ ./push_to_gitee.sh            # 推送所有子模块               │
│  $ ./push_to_gitee.sh --status   # 查看子模块状态               │
│  $ ./push_to_gitee.sh --list     # 列出子模块                   │
└────────────────────────────────────────────────────────────────────┘

┌─ 脚本3：push_to_gitee_ssh.sh (SSH版本) ──────────────────────┐
│                                                                    │
│  用途：使用SSH密钥推送子模块（更安全）                          │
│                                                                    │
│  推送内容：与 push_to_gitee.sh 相同                             │
│                                                                    │
│  前提条件：需要先配置SSH密钥                                    │
│  $ ./setup_gitee_ssh.sh          # 配置SSH密钥                  │
│                                                                    │
│  使用方法：                                                         │
│  $ ./push_to_gitee_ssh.sh        # 推送所有子模块（SSH）        │
└────────────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════════
  使用场景和推荐方案
═══════════════════════════════════════════════════════════════════════

场景1：完整项目推送（首次或定期备份）
┌────────────────────────────────────────────────────────────────────┐
│  推荐：push_all_repos.sh                                           │
│                                                                    │
│  $ ./push_all_repos.sh                                             │
│                                                                    │
│  推送：主仓库 + 所有子模块（6个仓库）                            │
│  耗时：约 1-3 分钟（取决于更改量）                                │
└────────────────────────────────────────────────────────────────────┘

场景2：只修改了脚本或文档
┌────────────────────────────────────────────────────────────────────┐
│  推荐：push_all_repos.sh --main-only                               │
│                                                                    │
│  $ ./push_all_repos.sh --main-only                                 │
│                                                                    │
│  推送：只推送主仓库（脚本、文档、配置）                          │
│  耗时：约 10-30 秒                                                 │
└────────────────────────────────────────────────────────────────────┘

场景3：只修改了代码（gem5、gem5-gpu等）
┌────────────────────────────────────────────────────────────────────┐
│  推荐：push_to_gitee.sh 或 push_all_repos.sh --subs-only          │
│                                                                    │
│  $ ./push_to_gitee.sh                                              │
│  或                                                                 │
│  $ ./push_all_repos.sh --subs-only                                 │
│                                                                    │
│  推送：只推送子模块（代码仓库）                                   │
│  耗时：约 1-2 分钟                                                 │
└────────────────────────────────────────────────────────────────────┘

场景4：修改了代码和文档
┌────────────────────────────────────────────────────────────────────┐
│  推荐：push_all_repos.sh                                           │
│                                                                    │
│  $ ./push_all_repos.sh                                             │
│                                                                    │
│  推送：主仓库 + 所有子模块                                         │
│  耗时：约 1-3 分钟                                                 │
└────────────────────────────────────────────────────────────────────┘

  推送日志
═══════════════════════════════════════════════════════════════════════

所有推送操作都会生成详细日志：

push_all_repos.sh:
  → build_logs/push_all_YYYYMMDD_HHMMSS.log

push_to_gitee.sh:
  → build_logs/git_push_YYYYMMDD_HHMMSS.log

查看最新日志：
  $ ls -lt build_logs/push_all_*.log | head -1
  $ cat build_logs/push_all_*.log | tail -50

  故障排除
═══════════════════════════════════════════════════════════════════════

问题：推送失败 - 认证错误
┌────────────────────────────────────────────────────────────────────┐
│  错误: Authentication failed                                       │
│                                                                    │
│  可能原因：                                                         │
│  1. Personal Access Token过期                                      │
│  2. 网络连接问题                                                    │
│                                                                    │
│  解决方法：                                                         │
│  1. 在Gitee上生成新的Personal Access Token                        │
│  2. 更新脚本中的GITEE_PASSWORD变量                                 │
│  3. 或切换到SSH方式（更稳定）                                      │
│     $ ./setup_gitee_ssh.sh                                         │
│     $ ./push_to_gitee_ssh.sh                                       │
└────────────────────────────────────────────────────────────────────┘

问题：推送速度慢
┌────────────────────────────────────────────────────────────────────┐
│  原因：子模块较大，网络速度限制                                    │
│                                                                    │
│  优化方法：                                                         │
│  1. 只推送修改的仓库                                                │
│     $ ./push_all_repos.sh --main-only  （如果只改了文档）         │
│  2. 使用增量推送（Git自动处理）                                    │
│  3. 考虑使用SSH（通常更快）                                        │
└────────────────────────────────────────────────────────────────────┘

问题：某个子模块推送失败
┌────────────────────────────────────────────────────────────────────┐
│  现象：其他仓库成功，某一个失败                                    │
│                                                                    │
│  解决方法：                                                         │
│  1. 查看日志文件了解原因                                            │
│     $ cat build_logs/push_all_*.log | grep "✗"                    │
│  2. 手动推送失败的仓库                                              │
│     $ cd gem5  # 假设gem5推送失败                                  │
│     $ git status                                                   │
│     $ git push                                                     │
│  3. 重新运行完整推送                                                │
│     $ ./push_all_repos.sh                                          │
└────────────────────────────────────────────────────────────────────┘
