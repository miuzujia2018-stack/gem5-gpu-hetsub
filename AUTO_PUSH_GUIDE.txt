  修改推送时间
═══════════════════════════════════════════════════════════════════════

Cron时间格式
┌────────────────────────────────────────────────────────────────────┐
│  格式：分 时 日 月 星期                                             │
│                                                                    │
│  字段说明：                                                         │
│  • 分钟 (0-59)                                                     │
│  • 小时 (0-23)                                                     │
│  • 日期 (1-31)                                                     │
│  • 月份 (1-12)                                                     │
│  • 星期 (0-7, 0和7都表示周日)                                      │
└────────────────────────────────────────────────────────────────────┘

常用时间示例
┌────────────────────────────────────────────────────────────────────┐
│  0 2 * * *     → 每天凌晨2点 (默认)                                │
│  0 3 * * *     → 每天凌晨3点                                        │
│  0 1 * * *     → 每天凌晨1点                                        │
│  30 2 * * *    → 每天凌晨2点30分                                    │
│  0 2 * * 1-5   → 工作日凌晨2点                                      │
│  0 2 * * 0     → 每周日凌晨2点                                      │
│  0 */6 * * *   → 每6小时一次                                        │
│  0 0 1 * *     → 每月1号午夜                                        │
└────────────────────────────────────────────────────────────────────┘

修改时间步骤
┌────────────────────────────────────────────────────────────────────┐
│  1. 编辑cron任务                                                    │
│     $ crontab -e                                                   │
│                                                                    │
│  2. 修改第一列的数字                                                │
│     例如改为凌晨3点：                                               │
│     0 3 * * * /home/siat/gem5-gpu-bak/auto_push_wrapper.sh        │
│                                                                    │
│  3. 保存退出（:wq 或 Ctrl+X）                                       │
│                                                                    │
│  4. 验证修改                                                        │
│     $ crontab -l                                                   │
└────────────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════════
  WSL特别说明
═══════════════════════════════════════════════════════════════════════

WSL的Cron限制
┌────────────────────────────────────────────────────────────────────┐
│  问题：WSL在Windows睡眠时会暂停                                     │
│                                                                    │
│  解决方案：                                                         │
│                                                                    │
│  方法1：保持Windows运行                                             │
│  • 在凌晨2点前不要让Windows进入睡眠                                │
│  • 调整Windows电源设置                                              │
│                                                                    │
│  方法2：使用Windows Task Scheduler                                  │
│  • 创建Windows计划任务                                              │
│  • 任务操作：wsl.exe -e /home/siat/gem5-gpu-bak/auto_push_wrapper.sh │
│  • 触发器：每天凌晨2点                                              │
│  • 优点：即使WSL未运行，Windows会启动它                            │
└────────────────────────────────────────────────────────────────────┘

Windows Task Scheduler设置
┌────────────────────────────────────────────────────────────────────┐
│  1. 打开"任务计划程序" (Task Scheduler)                            │
│                                                                    │
│  2. 创建基本任务                                                    │
│     • 名称：Git Auto Push                                          │
│     • 触发器：每天                                                  │
│     • 时间：凌晨2:00                                                │
│                                                                    │
│  3. 操作：启动程序                                                  │
│     • 程序：wsl.exe                                                │
│     • 参数：-e /home/siat/gem5-gpu-bak/auto_push_wrapper.sh       │
│                                                                    │
│  4. 条件（可选）                                                    │
│     ☑ 唤醒计算机运行此任务                                         │
│     ☑ 只有在计算机使用交流电源时才启动                             │
└────────────────────────────────────────────────────────────────────┘
