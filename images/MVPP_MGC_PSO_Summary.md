## Summary

Modern heterogeneous manycore architectures integrating CPU and GPU processing units enable diverse computing choices for concurrent application execution. This requires communication fabric capable of efficiently handling heterogeneous traffic patterns generated by concurrently running CPU and GPU applications. In this paper, we propose MVPP_MGC_PSO, an adaptive routing algorithm based on Multi-Vehicle Path Planning with Multi-Group Clustering and Particle Swarm Optimization, that provides efficient communication support for concurrently running applications in heterogeneous CPU-GPU systems. MVPP_MGC_PSO organizes different types of packets (CPU packets, GPU packets, coherence protocol packets) into specialized swarms, enabling local optimization within swarms and global collaboration across swarms. Each dynamically-configured swarm is capable of employing different optimization strategies for routing decisions according to the communication requirements of its corresponding processing unit type, including latency minimization, congestion avoidance, power optimization, and load balancing. In addition, we apply Particle Swarm Optimization to design a multi-objective fitness function that dynamically optimizes routing path selection through iterative updates of particle velocities and positions, with the aim of improving network performance and energy efficiency. We evaluate MVPP_MGC_PSO using mixed workloads from GPU benchmark suite (Rodinia) and CPU benchmark suites (PARSEC, SPLASH-2). The simulation results show that MVPP_MGC_PSO can achieve 21.4% latency reduction, 20.7% execution time improvement, and 25.6% NoC energy efficiency enhancement when compared to the baseline mesh routing. Compared to the state-of-the-art TB-TBP routing algorithm, MVPP_MGC_PSO achieves 15.1% hop count reduction on CPU applications and a remarkable 17.1% improvement on GPU applications, benefiting from its processing-unit-aware multi-swarm collaborative optimization mechanism that effectively adapts to the dynamic characteristics of GPU bursty traffic.
