## Abstract

With the rapid development of heterogeneous computing systems, modern Network-on-Chip (NoC) faces the challenge of simultaneously supporting diverse traffic patterns generated by concurrent execution of CPU and GPU applications. Traditional static routing algorithms struggle to adapt to the dynamic communication requirements of heterogeneous workloads, resulting in increased network latency, severe congestion, and degraded energy efficiency. To address this problem, this paper proposes MVPP_MGC_PSO (Multi-Vehicle Path Planning with Multi-Group Clustering and Particle Swarm Optimization), an adaptive routing algorithm for heterogeneous CPU-GPU systems. MVPP_MGC_PSO organizes different types of packets into specialized swarms and implements processing-unit-aware routing decisions through a multi-swarm collaborative optimization framework. The algorithm employs Particle Swarm Optimization to dynamically explore optimal routing paths, incorporating a multi-objective fitness function that simultaneously optimizes latency, congestion, power consumption, and reliability. Through local optimization within swarms and knowledge sharing across swarms, MVPP_MGC_PSO effectively adapts to the heterogeneous communication patterns of CPU and GPU applications, particularly the dynamic characteristics of GPU bursty traffic. We comprehensively evaluate the algorithm using mixed workloads from Rodinia GPU benchmark suite and PARSEC, SPLASH-2 CPU benchmark suites. Experimental results demonstrate that compared to traditional mesh routing, MVPP_MGC_PSO achieves 21.4% network latency reduction, 20.7% execution time improvement, and 25.6% NoC energy efficiency enhancement. Compared to the state-of-the-art TB-TBP routing algorithm, MVPP_MGC_PSO achieves 15.1% hop count reduction on CPU applications and a remarkable 17.1% improvement on GPU applications, validating its superior performance in heterogeneous systems.

**Keywords**: Network-on-Chip, Heterogeneous CPU-GPU Systems, Particle Swarm Optimization, Adaptive Routing, Multi-Swarm Collaboration
